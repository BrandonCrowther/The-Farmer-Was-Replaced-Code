## Main Menu / Windows

### `Load`

Load or create a different save.

### `Save`

Saves the game.

### `New Game`

Create a new save.

### `Open Folder`

Open the save folder in the file explorer.

### <a href="Tooltips_Options" class="wikilink" title="Options"><code>Options</code></a>

Opens the <a href="Tooltips_Options" class="wikilink" title="options">options</a> menu.

### `Discord`

Join the discord to chat with other players and the developer, report bugs or get help.

### `New Function`

Create a new code file.

### `New Info Window`

Open a new info window.

### `Minimize`

Minimizes this window.

### `Delete`

Permanently delete this file.

### `Close Docs`

Close this window.

### `Table of Contents`

Table of Contents

### `Open Unlock Menu`

Open the unlock tree.

## Code Window

### `Execute`

Starts or stops execution of the code in this window.

### `Step by Step`

Executes one step of the code.

## Search

### `Toggle Search Docs`

Toggles if the search should include docs windows.

### `Toggle Search Code`

Toggles if the search should include code windows.

### `Next Search`

Go to the next match of the search term.

### `Previous Search`

Go to the previous match of the search term.

### `Close Search`

Close the search menu.

## Other

### Warning Icon

Your code triggered a warning. Click the icon to view details in the Output window.

## Keybinds

### `Indent Selection`

Add indentation to all selected lines. This needs to be a key that inserts a character for it to work. So any combinations with ctrl or alt won't work.

### `Unindent Selection`

Remove indentation from all selected lines. This needs to be a key that inserts a character for it to work. So any combinations with ctrl or alt won't work.

### `Menu`

Open or close the main menu.

### `Move Up / Down / Left / Right`

Move the camera in the corresponding direction.

### `Redo`

Redo the last undo.

### `Save`

Save the game.

### `Undo`

Undo the last change.

### `Search`

Search for a search term in all windows.

### `Start Execution`

Starts the execution of the most recently active file or resumes it if it's paused.

### `Stop Execution`

Stops the execution.

### `Next Step`

Perform one step if the execution is paused.

### `Pause Execution`

Pause the execution.

### `Hide UI`

Hide or unhide the HUD.
