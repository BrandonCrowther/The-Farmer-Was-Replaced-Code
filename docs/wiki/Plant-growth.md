This page documents information about plant growth that the game doesn't provide.

## Plant growth time distribution

The growth time of each plant is a random number with a uniform distribution within a range depending on the plant. The ranges are provided by the following table:

| Plant | Minimum | Mean | Maximum |
|----|----|----|----|
| <a href="Grass" class="wikilink" title="Grass">Grass</a> | 0.5 | 0.5 | 0.5 |
| <a href="Bush" class="wikilink" title="Bush">Bush</a> | 3.2 | 4.0 | 4.8 |
| <a href="Carrots" class="wikilink" title="Carrots">Carrots</a> | 4.8 | 6.0 | 7.2 |
| <a href="Tree" class="wikilink" title="Tree">Tree</a> | 5.6 | 7.0 | 8.4 |
| <a href="Pumpkins" class="wikilink" title="Pumpkin">Pumpkin</a> | 0.2 | 2.0 | 3.8 |
| <a href="Cactus" class="wikilink" title="Cactus">Cactus</a> | 1.0 | 1.0 | 1.0 |
| <a href="Sunflowers" class="wikilink" title="Sunflower">Sunflower</a> | 5.6 | 7.0 | 8.4 |
| <a href="Dinosaurs" class="wikilink" title="Dinosaur">Dinosaur</a> | 0.18 | 0.2 | 0.22 |
