## Overview

Grass is the first entity that can be harvested on the farm. Harvesting it produces Hay, which is required for several initial <a href="unlocks" class="wikilink" title="unlocks">unlocks</a>. Grass grows automatically on <a href="Grounds" class="wikilink" title="grassland">grassland</a>.
